Пишем тесты первыми, реализацию — вторыми

Meeting Brain · Claude Code Advanced

Задание

Реализуй базовый модуль meetings в NestJS используя TDD. Claude должен сам итерировать до зелёных тестов.

POST
/meetings
Создать новую встречу. Принимает title, date, participants[]
тест #1
GET
/meetings
Получить список всех встреч текущего пользователя
тест #2
GET
/meetings/:id
Получить одну встречу по ID. Вернуть 404 если не найдена
тест #3

Порядок работы с Claude

1

Попроси написать тесты

Сначала только тесты — без реализации. Три теста для трёх эндпоинтов.

2

Запусти — убедись что красные

npm run test — все три теста должны упасть. Это ожидаемо.

3

Попроси написать реализацию

Попроси Claude реализовать модуль под тесты. Он сам запустит тесты и будет итерировать.

4

Дождись зелёного

Не вмешивайся — наблюдай как агент сам получает сигнал и правит код.

Главное в упражнении — не написать код, а увидеть как Claude итерирует через тесты
