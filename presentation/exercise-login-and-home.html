Упражнение

Логин и главная страница

Claude итерирует через Playwright — без вашего участия

Meeting Brain · Claude Code Advanced

Задание

Попроси Claude реализовать две страницы. Он должен проверять результат через Playwright после каждого изменения — автоматически, по правилам из CLAUDE.md.

1 Страница логина /auth/login

  • Форма с полями email и пароль
  • Кнопка "Войти"
  • Ссылка на регистрацию
  • Подключена к POST /auth/login
  • После логина — редирект на /
  • Показывает ошибку при неверных данных

2 Главная страница /

  • Доступна только авторизованным
  • Приветствие с email пользователя
  • Количество встреч
  • Список последних 3 встреч
  • Кнопка "Создать встречу"
  • Кнопка выхода из аккаунта

Порядок работы

1

Дай задачу Claude

Опиши обе страницы одним промптом. Не уточняй детали реализации — пусть решает сам.

2

Наблюдай за итерациями

Claude должен сам делать скриншоты через Playwright и исправлять визуальные проблемы.

3

Проверь функциональность

После завершения попроси Claude самостоятельно протестировать логин: ввести данные, нажать кнопку, проверить редирект.

4

Проверь защиту роута

Попроси Claude открыть / без авторизации и убедиться что редирект на логин работает.

Не вмешивайся пока Claude работает — главное увидеть как он сам итерирует через браузер

Что проверяем

Визуально

  • Страница логина выглядит аккуратно
  • Нет элементов прижатых к краям
  • Главная читаемая и структурированная
  • Claude делал скриншоты сам

Функционально

  • Логин работает с верными данными
  • Ошибка при неверных данных
  • / недоступна без авторизации
  • Выход очищает сессию

Не нужно — красивые анимации, мобильная адаптация, смена пароля. Фокус на браузерном feedback loop.
